# HGL Method Toggle Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a global project setting that switches HGL computation between HEC-22 (default) and a conservative method that pins each structure's upstream HGL to its outgoing pipe's upstream crown.

**Architecture:** One change point in `computeStructureCalc` — every surface (HGL tabs, detail sheets, print package, Excel export) reads `calc.elevation`, so the pin propagates everywhere without duplication. A new `state.hydraulics.hglMethod` field is persisted through quick-save snapshots and a `HGL Method` row on the Excel "Rainfall Settings" sheet.

**Tech Stack:** Single-file HTML app (all JS inline, IIFE-wrapped), SheetJS for Excel, `node:test` + jsdom test harness in `tests/run-tests.mjs`.

**Design spec:** `docs/superpowers/specs/2026-11-08-hgl-method-toggle-design.md` (approved — requirements there are binding).

3. All state-mutating input handlers route through `withFocusPreserved` (app spec §A.2).
4. Commit format: `feat(calculator): <slug>` or `test(calculator): <slug>`. **Never add LLM attribution trailers** (no `Co-Authored-By` lines).
5. Run tests from the `tests/` directory: `node --test run-tests.mjs`. The suite currently passes 76/76; every task must keep it green.

**Conventions used in the code (follow existing style):**

- DOM built with the `el(tag, attrs, children)` helper; `el("option", {value:v}, label)`.
- Tests reach the app through `window.__sdc` (exposed at the bottom of the dev file under the comment `// Exposed for debugging / automated testing only - not used by the UI.`).
- Tests that need custom networks swap `sdc.state.structures` / `sdc.state.pipes` / `sdc.state.kb` with save/restore (see `run-tests.mjs` lines 536–583 for the pattern).

**Test fixture math (deterministic, used throughout):** structures with `drainageAreaId: ""` carry Q = 0, so Sf = 0, Hf = 0, Vout = 0, Hb = 0. Therefore `elevation = downstreamElev` exactly, independent of Kb tables. With a 24" circular pipe whose `upstreamInvert` is 99: crown = 99 + 24/12 = 101.00 ft. With the outfall fixed at 100.00 ft, the HEC-22 HGL is 100.00 (< crown 101.00 → pin applies); with the outfall at 102.00 the HGL is 102.00 (≥ crown → no pin).
